# Spec 15: Greet a visitor by name (backend)

## Scope

This repo meets R1 and R2. R3–R6 belong to the frontend; this repo only provides the API the page calls.

Open question from the Requirement (trimming): this spec assumes the **backend trims** leading and trailing spaces
before greeting and before counting length. The frontend may also trim, but doesn't have to. If the Requirement's
owner decides otherwise, change the "trim" step in Design and checks R2.4 and R1.2.

## Design

Add one route to `routes` in `src/app.js`, with a small helper `greet(body)`. No new files, no dependencies.

### `POST /greet`

Request body: `{"name": "<string>"}`

| Case | Status | Body |
| --- | --- | --- |
| `name` is a string whose trimmed form is 1–50 characters | 200 | `{"greeting": "Hello, <trimmed name>!"}` |
| trimmed `name` is longer than 50 characters | 400 | `{"error": "name is too long (at most 50 characters)"}` |
| `name` missing, not a string, or empty/only spaces after trimming | 400 | `{"error": "name is required"}` |

Rules:
- Trim with `String.prototype.trim()`, then check length (`name.length`, in UTF-16 units).
- The name is inserted as plain text, with no escaping or other change; the frontend shows it as text.
- A missing `body` (undefined) is treated like a missing `name`.

## Acceptance checks

Tests go in `tests/app.test.js`, calling `handle({method: "POST", path: "/greet", body})`.

- R1.1: `{name: "Ada"}` → status 200, body `{greeting: "Hello, Ada!"}`.
- R1.2: `{name: "  Ada  "}` → status 200, body `{greeting: "Hello, Ada!"}`.
- R1.3: `{name: "<b>Ada</b>"}` → status 200, greeting `Hello, <b>Ada</b>!` (unchanged).
- R2.1: a name of exactly 50 characters (`"a".repeat(50)`) → status 200, greeting `Hello, <name>!`.
- R2.2: a name of 51 characters → status 400, body `{error: "name is too long (at most 50 characters)"}`.
- R2.3: a name of 200 characters → status 400, same error body.
- R2.4: 50 characters padded with spaces on both sides (total over 50) → status 200 (length is counted after trimming).
- R2.5: `{name: ""}`, `{name: "   "}`, `{}`, `{name: 42}` and an undefined body → status 400, body `{error: "name is required"}`.

## Not in this spec

- The page, its field and button, empty-name handling in the page, showing errors, and escaping on display (R3–R6): frontend.
- Other languages or greeting formats, name history, name content checks beyond length, auth, rate limiting, logging.
- Unreachable-backend handling.
